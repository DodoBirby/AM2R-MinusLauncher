By default, this directory only contains libopenal.so.1, its license, and this readme. The rest of the libraries are populated from the autopatcher (https://github.com/AM2R-Community-Developers/AM2R-Autopatcher-Linux).
Because the autopatcher includes no license for its libraries, I also do not include one.

The 32-bit OpenAL library is built on my personal Arch Linux install, using the AUR version (https://aur.archlinux.org/packages/lib32-openal). I found it quite a pain to compile, so I have chosen to re-distribute it.
All libraries here, both obtained from the autopatcher and included with the lancher, are to be run at your own risk.
